# Irodori TTS for iPhone 0.3.0（未リリース）

- iPhoneでCore ML現行版／軽量INT8版と、speech.cpp 0.8.10 / MetalのIrodori v4.1 Small MF F16を生成・試聴・比較できます。
- `IrodoriSpeechCpp` Swift PackageでMetal TTSとReazonSpeech Q4_Kの音声認識を利用できます。
- 必要なモデルのダウンロード・検証・削除と、方式切替時の排他解放に対応。同じ方式ではモデルを再利用します。
- 生成後の自動再生、保存済みWAVの再生と再起動後の結果復元に対応します。
- ロード・参照準備・推論時間・RTF、アプリ全体RAMの現在値と処理中の最大観測値を表示します。
- 耳ボタンからbeam／greedy、録音／ファイル入力による音声認識を試せます。
- Core MLだけのiPhone / Macサンプルと、iPhone比較アプリをそれぞれのプロジェクトでビルドできます。
- ビルド済みspeech.cppライブラリを同梱し、Xcodeでプロジェクトを開いてTeamとBundle Identifierを設定するだけでビルドできます。
